## 一、需求背景与目标

第一板（M0–M10）已完成记账核心闭环：流水、账户（3 类）、预算、周期记账、模板、报表、备份恢复、回收站、生物锁、桌面小部件。v1.8.0 的目标是**完善资产视角与导航结构**：

1. 账户体系从 3 类（资金/信用/借贷）拆成 **5 类**，新增现金、储蓄卡、投资；
2. 投资账户支持「成本 + 市值」手动管理，自动算盈亏（不联网）；
3. 账户页升级为「资产中心」：合并待报销、借贷台账入口，新增资产报表；
4. 首页导航重构：底部三 Tab + 悬浮记账按钮 + 左上角汉堡抽屉；
5. 预算以概览卡形式下沉到明细主界面底部。

| D11 | 抽屉内容 | 模板 / 周期记账 / 备份与恢复 / CSV导出 / 回收站 / 分类管理 / 设置（七项，借贷不放） |

| D13 | 净资产趋势 | 按月（近 12 个月）/ 按年切换，从历史流水回算，不存快照 |
| D14 | 变化记录 | 只记真正改变净资产的事；**转账不记**；每条显示日期/事件/金额/变动后净资产 |

## 六、数据定义与口径（全 App 统一）

### 6.1 账户类型（枚举扩为 5 种）

| 枚举 | 含义 | 余额/字段语义 |
|---|---|---|
| `CASH` | 现金 | ≥0 正余额 |
| `SAVINGS` | 储蓄卡 / 电子钱包 | ≥0 正余额 |
| `CREDIT` | 信用卡、花呗等 | 负余额 = 欠款 |
| `DEBT` | 借出 / 借入 | 方向由 DebtDirection 决定 |
| `INVEST` | 投资账户 | `costCents`（累计成本）+ `marketValueCents`（当前市值）+ `includeInNetAssets`（默认 true） |

### 6.2 投资账户规则

- 买入 = 转入（转账：现金/储蓄卡 → 投资账户）；卖出 = 转出；复用 TRANSFER，**不新增流水类型**；
- 转入/转出自动累加/扣减 `costCents`；
- **改市值不生成流水**，盈亏 = 市值 − 累计成本，实时现场计算；
- 红涨绿跌：盈利红色、亏损绿色。

### 6.3 净资产口径（替换现有 AssetSummary）

| 项 | 计算 |
|---|---|
| 总资产 | Σ现金余额 + Σ储蓄卡余额 + Σ计入净资产的投资账户市值 |
| 总负债 | Σ信用账户欠款 + Σ借贷净负债 |
| 净资产 | 总资产 − 总负债 |

### 6.4 资产变化记录（只记真正改变净资产的事）

| ✅ 记录 | ❌ 不记录 |
|---|---|
| 收入、支出、退款 | **转账**（含投资买入/卖出，一减一增） |
| 坏账核销、删除流水 | 账户间互转 |
| 修改初始余额 | — |
| 修改市值（事件名「调整市值」，金额 = 新市值 − 旧市值） | — |

- 每条记录：日期 + 事件描述（如「餐饮支出」「调整市值：某某基金」）+ 金额（+绿/−红）+ 变动后净资产；
- 数据由流水表回算生成（查询/视图），**不单独建表**；删除的流水沿用现有回收站机制追溯。
