# 一心记账

一个**纯本地**的安卓记账 App。记一笔不超过三秒，数据只存在你自己的手机里——不联网、不注册、不上传。

| 项目 | 说明 |
|---|---|
| 包名 | `com.xxjz.ledger` |
| 最低版本 | Android 11（API 30） |
| 目标版本 | Android 15（API 35） |
| 语言 / 界面 | Kotlin 2.2 + Jetpack Compose（Material 3），**零 XML 布局** |
| 当前版本 | 1.7.0（versionCode 8） |

---

## 一、功能一览

**记账**

- 支出 / 收入 / 转账三类流水，计算器键盘（`12.5 + 8 × 2` 直接算），大按钮键盘可选
- 分类两级（大类 + 小类），标签、商家、备注（限 200 字）
- 模板：常用账目一键记；周期记账：按天/周/月/年，支持次数与截止日期
- 待报销、退款（红冲）、借贷台账

**看账**

- 明细按月，按天分组带日小计；日历视图看哪天有账
- 报表：饼图/柱状/趋势，按大类下钻，年度总结（12 个月双柱 + Top3 分类/商家）
- 预算：总预算与分类预算，超支提醒，日均可用额度
- 账户：多账户、净资产汇总（资产 - 负债）、隐藏账户不计入

**数据**

- 加密备份：AES-256-GCM + PBKDF2（12 万轮），导出的 `.bak` 没有密码打不开
- 覆盖导入，导入失败整体回滚；版本不兼容会明确提示而不是写坏数据
- CSV 导出（明细 / 按分类 / 按月）
- 回收站：删除的流水/账户/预算先进回收站，保留天数可设（7/15/30/90/永久）

**系统集成**

- 桌面小组件：本月收支 + 结余，点一下直接记账
- 桌面快捷方式：记一笔 / 报表 / 搜索
- 每日记账提醒（当天已记过就不打扰）
- 应用锁：PIN（4~8 位，PBKDF2 哈希存储）+ 指纹/面容，后台 60 秒宽限期
- 深色模式、收支配色反转、小数位 0~2 位

## 二、如何构建

### 环境要求

- JDK 17（`JAVA_HOME` 指向它）
- Android SDK，含 Platform 35 与 Build-Tools 35
- 无需联网依赖：仓库里已锁定版本，加 `--offline` 可完全离线构建

### 命令

```bash
export ANDROID_HOME=/path/to/android/sdk
export JAVA_HOME=/path/to/jdk17

# 调试包
./gradlew assembleDebug

# 发布包（会做 R8 混淆 + 资源压缩）
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk

# 单元测试（460 个用例）
./gradlew testDebugUnitTest

# 代码规范
./gradlew ktlintCheck detekt
```

内存吃紧的机器上建议加 `--no-parallel --max-workers=1`，避免 Gradle 守护进程被 OOM 杀掉。

### 签名说明

自用版本使用本机 debug keystore 签名（`app/build.gradle.kts` 里 `signingConfig = signingConfigs.getByName("debug")`）。

- **密钥文件不进仓库**：`.gitignore` 已排除 `*.jks` / `*.keystore` / `local.properties`
- 换机器打包前，先把原 `~/.android/debug.keystore` 拷过去，否则签名不同、无法覆盖安装（需先卸载，卸载会清空数据）
- 如果将来要上架，改成正式 signingConfig 并妥善保管 keystore：**丢了这个文件，老用户就无法升级**

## 三、如何备份与恢复

备份是**唯一**的跨设备迁移手段，也是误删全库后的最后一道防线。

### 备份

1. 我的 → 备份与恢复 → 导出备份
2. 设置密码（至少 6 位，建议记在密码管理器里）
3. 选择保存位置，得到一个 `.bak` 文件

> 密码丢失后**无法恢复**。加密是端到端的，开发者也没有后门。

### 恢复

1. 我的 → 备份与恢复 → 选择备份文件
2. 输入密码 → 看到「将导入 N 笔流水」的预览 → 确认
3. 导入是**整库覆盖**：当前所有数据会被备份内容替换，中途失败会自动回滚

### 建议

- 每月导出一次，文件放网盘或电脑上（App 自己不联网，这一步需要你手动做）
- 回收站默认保留 30 天，误删先看回收站，别急着导入备份

## 四、已知限制

| 限制 | 说明 |
|---|---|
| 不联网 | 没有登录、没有云同步、没有多设备共享。这是设计选择，不是缺失 |
| 提醒可能延迟 | 国产 ROM 的后台限制会让定时任务晚几分钟甚至更久。App 启动时会补执行周期记账，**账目不会漏，只是提醒可能迟到** |
| 备份需手动搬运 | App 不联网，备份文件要自己拷到网盘/电脑 |
| 小组件刷新受系统调度 | 桌面小组件的更新频率由系统决定，通常跟随主界面使用而刷新 |
| 无多币种换算 | 币种字段目前固定 CNY，仅保留结构，不做汇率换算 |
| 不支持的导入格式 | 只认本 App 的加密 `.bak`；CSV 只能导出不能导入（防止字段映射出错导致脏数据） |
| 桌面端 | 无。只有安卓手机端 |

## 五、隐私

- **不申请 INTERNET 权限**：连技术上都无法联网，抓包也抓不到东西
- 只申请三条普通人能理解的权限：通知（提醒）、生物识别（应用锁）、开机自启（恢复定时任务）
- 无埋点、无统计 SDK、无广告
- 备份文件加密后存储，App 私有目录下的数据库不对外暴露

权限清单有自动化测试守着（`ManifestPermissionTest`）：如果以后有依赖偷偷往清单里合并网络/通讯录权限，构建会直接失败。

## 六、代码结构

```
app/src/main/java/com/xxjz/ledger/
├── core/            # 跨功能基础设施
│   ├── common/      # 金额、日期、PIN 哈希、提醒计划、抽象日志
│   ├── designsystem/# 主题、通用组件
│   └── ui/chart/    # 自绘饼图/柱状/折线
├── data/
│   ├── local/       # Room：实体、DAO、迁移、种子数据
│   ├── datastore/   # DataStore：全部偏好设置
│   ├── backup/      # 备份编解码、加密、映射
│   ├── repository/  # 仓库实现
│   └── worker/      # 周期记账、回收站清理、每日提醒
├── domain/          # 模型、仓库接口、用例（纯 Kotlin，无 Android 依赖）
├── feature/         # 按页面分包，每个包 = Screen + ViewModel
├── navigation/      # 路由表与导航图
├── ui/lock/         # 应用锁
└── widget/          # Glance 桌面小组件
```

分层约定：

- `domain` 不依赖 Android，方便纯 JVM 单测
- `feature` 通过仓库接口拿数据，不直接碰 DAO
- 聚合计算放在 DAO 的 SQL 里（有索引），不把全表拉到内存里算

## 七、测试

```bash
./gradlew testDebugUnitTest
```

当前 **460 个用例全绿**，覆盖：

| 类型 | 内容 |
|---|---|
| 纯逻辑单测 | 金额格式化、计算器引擎、日期、周期推算、预算进度、报表聚合 |
| ViewModel 测 | 每个页面的状态流转、边界与错误提示 |
| DAO 集成测 | 真实 SQLite 上验聚合 SQL、软删除过滤、索引命中 |
| 备份往返 | 导出 → 导入 → 逐字段比对；损坏文件、密码错误、版本不兼容 |
| 权限审计 | 断言清单里没有网络/通讯录/短信权限 |
| 性能压测 | 5000 笔账目下聚合 < 300ms、分组 < 200ms（实测 1ms / 11ms） |

性能用例给的是明确上限而不是打印耗时，写坏查询（N+1、全表扫描）会直接红。
